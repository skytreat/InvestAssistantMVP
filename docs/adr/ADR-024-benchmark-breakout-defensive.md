## 1. 背景

### 1.1 §13.16 之后剩下的唯一杠杆

§13.15/§13.16 依次否决了四条路径（黄金腿加权、volWindow 调优、扩池加债券、防御回退），
判定「**基线 Calmar 0.44 是当前 7 只池 + 同一套动量过滤下的实测上限**」。

§13.16 给出的**根因**是关键：

> 债券腿与 A 股池日收益相关性 **−0.12 ~ −0.28**（比黄金腿的 +0.07~+0.19 分散度更高），
> **理论上**该显著降 MDD；但扩展标的仍走**同一套 L1 过滤链**（MA 多头 + 动量区间 + 日涨跌 +
> 基准门槛），债券 WSM 动量长期贴近 0 或为负 ⇒ **成交标的实测只有原 7 只池，债券腿一笔未成交**。

⇒ 这是**信号层与资产层的错配**：想用低相关资产，就必须**给它一条不依赖股票动量的入场规则**。

### 1.2 §13.8 的依据错误（已更正）

§13.8 记载「`sh000300` WSM 动量 1,891 天**全 > 0**」⇒ 据此判定「基准软化零效果」。
**用项目自己的 `calcWeightedSlopeMomentum` 实测：WSM < 0 占 52.1%（1087/2085 天），不是 0 天。**

**结论**（基准软化零效果）经 §13.17.3 复测**仍然成立**（soft vs hard 逐位相同），
但**依据是错的** —— 正确解释是「即使基准 52% 的天动量为负，`soft` 放行后那些标的也
没能通过其余过滤条件」。

⇒ 既然基准动量**确实有 52% 的天为负**，那么「基准动量破位」就是一个**可用信号**。

---

## 2. 决策

### 2.1 机制（已落地，opt-in，缺省关闭）

| 参数 | 缺省 | 语义 |
|---|---|---|
| `benchmarkBreakoutThreshold` | `0`（关闭） | 基准主槽动量（WSM）< 该阈值 ⇒ 强制清掉非防御持仓，全仓持有 `defensiveSymbol` |
| `benchmarkBreakoutHysteresis` | `0.3` | 已在防御态时，需基准动量回升到 `threshold + hysteresis` 才切回股票（抑制换手抖动） |

- 防御标的复用 §13.16 的 `defensiveSymbol`；
- 切换沿用框架既有 `defensive-fallback` 退出原因；
- **缺省 `threshold=0` ⇒ 缺省路径逐位不变**（`--check-baseline` 可验）。

### 2.2 实测结论（跑赢档 + vol(0.12) 之上）

| 组合 | CAGR | MDD | Calmar | 超额 |
|---|---|---|---|---|
| ADR-022 基线 | 11.65% | 26.46% | 0.44 | +5.63pp |
| **破位 th=−0.5 + 债券** | 10.57% | **18.97%** | **0.56** | +4.55pp |
| 破位 th=−0.3 + 债券 | 7.89% | 16.36% | 0.48 | +1.87pp |
| 破位 th=−0.5 + 货币 ETF | 10.29% | 19.20% | 0.54 | +4.27pp |

**阈值 −0.5 是最佳点**（触发 69 天、切换 19 次）。

---

## 3. 待 owner 裁决：目标函数的取舍

本 ADR **不改任何默认值**。采纳与否是一个**目标函数层面的取舍**，必须由 owner 拍板：

| 选项 | 收益 | 代价 |
|---|---|---|
| **A. 不采纳**（当前状态） | 维持 CAGR 11.65% / 超额 **+5.63pp** | Calmar 停在 0.44、MDD 26.46% |
| **B. 采纳 th=−0.5 + 债券** | MDD 26.46% → **18.97%**（−7.49pp）、Calmar 0.44 → **0.56**（**+27%**） | CAGR 11.65% → **10.57%**（−1.08pp）、超额 +5.63pp → **+4.55pp** |

> ⚠️ **关键**：ADR-022 定的目标函数是「**跑赢 `sh510300`**」（超额 +5.63pp）。
> 选项 B 下超额**降到 +4.55pp** —— 仍跑赢，但**目标达成度下降**。
> ⇒ 若 owner 的目标是「跑赢」且以超额为唯一尺度，**A 更优**；
> 若目标是「跑赢 + 可接受的最大回撤」（风险调整后收益），**B 更优**（Calmar 是风险调整后的收益尺度）。

**owner 选择后，本 ADR 补签字并把缺省值切过去 + 重跑 `--check-baseline` 锚新基线。**

## 4. 代价与风险

| 代价 / 风险 | 量化 | 缓解 |
|---|---|---|
| **CAGR 与超额下降** | −1.08pp / +5.63pp→+4.55pp | 见 §3 取舍；若 owner 选 A 则不发生 |
| **摩擦上升** | 8.62% → 9.36%/yr（+0.74pp） | 迟滞 0.3 把切换压到 19 次；若摩擦超预期可调迟滞 |
| **单一样本期** | 2019-01-02 ~ 2026-11-06，7 只池，1 次回测 | 未做样本外/滚动窗口验证；§12.7 明确不建议在网格上继续调参 |
| **信号与 §13.16 防御回退的耦合** | 两条触发路径（破位 / 无候选）共用 `defensiveSymbol` | 已实现为同一分支，无冲突 |
| **防御腿本身的回撤** | 债券 ETF 2021–2022 也有回撤（MDD 16.03% 并非全对冲） | 已含在实测的 18.97% 里 |

## 5. 被否决的备选方案

| 备选 | 否决理由 |
|---|---|
| **阈值 −0.3** | MDD 更低（16.36%）但 CAGR 塌到 7.89%、超额仅 +1.87pp ⇒ 过度防御 |
| **阈值 −0.7** | 样本期内仅 3 触发日，且触发日股票反而 +0.984%（已跌完）⇒ 无区分度 |
| **阈值 0（WSM 任意负值即切）** | 触发 52.1% 的天 ⇒ 长期半仓债券；且与 `benchmarkGateMode='soft'` 的放行方向相反，语义混乱 |
| **防御腿用货币 ETF `sh511880`** | MDD 19.20% / CAGR 10.29% ⇒ 全面劣于债券 `sh511260` |
| **回退标的一并加入候选池** | §13.16 B1a 实测：债券腿**一笔未成交**（进不了 L1 过滤链）⇒ 无效 |
| **改 `l1/params.ts` 的 `POOL_ORDER` 加债券** | 那是**对齐契约**（DAS-2），改动会让 L1 逐位对齐失效；本 ADR 用运行时池扩展避开 |

## 6. 附带的两个工程修复

| # | 问题 | 处置 |
|---|---|---|
| 1 | **`dmDiagnose.loadPanel()` 漏装实验标的** —— 只装 `FIXED_ETF_POOL + GLOBAL_ETF_POOL + DEFENSIVE_ETF + BENCHMARK + POOL_ORDER`，**不含** `sh511260` ⇒ 防御态下单成交不了 ⇒ **实际退化成「切现金」**，首轮实测报出虚高的 `CAGR 11.73% / MDD 16.03%` | 新增 `collectExperimentSymbols()`，**自动从 `BACKTEST_GROUPS` 收集**所有 `defensiveSymbol` / `poolExtension` 标的加入装载；修正后 `CAGR 10.57% / MDD 18.97%`，与独立复核（`loadSweepData` 全市场装载）**一致** |
| 2 | §13.8 的「基准动量 1,891 天全 > 0」**与实测不符**（实测 52.1% 为负） | §13.17.1 更正记载；**结论**（基准软化零效果）经复测仍成立，但依据改为「soft 放行后仍过不了其余过滤条件」 |

> 🔒 **教训**（写入 AGENTS.md 同源纪律）：**实验面板必须覆盖实验里会下单的全部标的**，
> 否则「成交不了」会静默退化成另一种行为（此处是切现金），**指标照样算得出来、结论照样错**。
