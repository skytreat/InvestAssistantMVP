# ADR-015 —— 资金校验只做行内自洽，不做账户级闭合
> 🔴 **编号说明（2026-10-21）**：本 ADR 原拟编号 **ADR-011**，因 Wave 8 收口后 `main` 已占用 ADR-011~ADR-012，**整体顺延为 ADR-015**（详见 `docs/adr/README.md`）。


> **状态**：已接受
> **日期**：2026-10-20
> **决策者**：owner
> **关联**：Requirements §2.9.3 / SDD_v3 §6 / plan T106

---

## 背景

初版设计打算做账户级资金闭合校验：
`Σ(资金发生额) + 期末资金余额 − 期初资金余额 = 0`

**实测否证了这个设计**：

| 检验 | 结果 |
|---|---|
| 「资金余额」列出现**百万级跳变**，而当日成交额仅几万 | 该列是**全账户总资产**，不是现金余额 |
| 同一账户的 ETF 交割单与股票交割单在重叠日期上余额仅差 120.90 | 两文件是**同一账户的品种筛选子集** |
| 逐笔闭合 `上笔余额 − 资金发生数 = 本笔余额` | **1 / 134 成立** |
| 账户级 `Σflow + 期末 − 期初` | 更不平 |

即：**每个导出文件只含自己品种的操作，而「资金余额」是全账户余额** ——
文件之间的缺口必然导致逐笔与账户级闭合全部失配。

> **这个错误来自一次小样本 generalize**：曾以 4 行样本得出「132/133 成立」，
> 全量复测为 1/134。小样本推断是本项目已确认的失败模式。

## 决策

**放弃账户级与逐笔余额闭合，改为逐行自洽校验**：

```
买入：资金发生额 = −(成交金额 + 费用合计)
卖出：资金发生额 = +(成交金额 − 费用合计)
```

**实测命中 145 / 148**（国泰 ETF 交割单 131/134 + 股票交割单 14/14）。
3 处不命中均为**现金分红**（无成交金额，`资金发生额` 即分红额，公式不适用）。

配套规则：

- **公式不适用的行单独归类**，不计入「不平行」统计
- 失配行按「费用口径不符 / 分红 / 口径未知」**分类报告**，不得笼统报「不平」
- **「资金余额」列不得当作现金余额使用**
- 校验的**适用范围必须声明**（无费用明细列的成交流水不参与）

## 后果

### 正面

- 校验**可机械断言**，且不受文件筛选方式影响
- 失配有分类，用户能看懂

### 负面 / 代价

- **失去了「账户总资金是否对得上」这个校验** —— 这是数据源本身的限制，无法通过实现弥补
- 差额归因**不能依赖资金闭合**，只能靠逐笔比对 + 归因表（ADR-013）

## 被否决的备选方案

| 备选 | 否决理由 |
|---|---|
| **做账户级闭合** | 实测 1/134，会产出**大量假警报**，用户直接失去信任 |
| **合并同账户全部文件后做闭合** | 实测合并后仍 7/147 —— 存在未导出的操作缺口（出入金、分红到账等） |
| **用费率反推校验** | 费率是配置值不是事实值，反推等于自证 |
| **放弃资金校验** | 行内自洽命中率 97.97%，是**可用**的强校验，放弃是浪费 |
