# ADR-017 —— V3 任务编号整体顺延 T100~T118 → T119~T137（解除与 v2 计划的撞号）

> **状态**：已接受
> **日期**：2026-10-24
> **决策者**：agent 自决（owner 授权「自决 + 记录待确认」，见 `docs/audit/v3-pending-decisions.md` D-1）
> **关联**：plan_v3 §2（任务总览）/ traceability §7bis / ADR-013~016「关联」行

---

## 背景

`code_implementation_plan_v2.md` 自 Wave 9 起已把任务编号用到 **T111**（T99~T103 行情链路修复与部署、T104~T109 Wave 11、T110~T111 Wave 12，均已合并入 `main`）。
而 `code_implementation_plan_v3.md` 初稿从 **T100** 起编号，造成 **T100~T111 共 12 个编号两套计划同号不同义**：

| 编号 | v2（已完成，在 main） | v3（待实施） |
|---|---|---|
| T100 | 部署态落地（unit + 运行用户 + 权限） | 送股/现金分红成本语义（core 扩展） |
| T101 | —（v2 未用） | 标的资产分类 |
| T102 | F8 验收升级 | 券商文件解析器 |
| T103 | 行情库备份开关（DEC-13） | 事实层三表 + 导入批次 |
| T104~T109 | Wave 11 行情 P0 修复 | 事件归一化 / 去重回填 / 资金校验 / 对账报告 / 现金类建模 / user_trade_record 改造 |
| T110 / T111 | Wave 12 前端体验 | 补录 / 交易对视图 |

撞号后果：项目铁律「一个 T 任务一条 commit，commit 消息带 T 号」+「回滚按 commit 区间 `git revert`」。
v3 的 `T103 feat: 事实层三表` 与 v2 已归档的 `T103 行情库备份开关` 在 git 历史中**无法区分**，
审计与回滚都会踩坑（`grep 'T103' git log` 命中两套任务）。

## 决策

**v3 的 19 个任务整体顺延为 T119~T137**（v2 现用最大编号 T111 + V3 首个任务从 T119 起，
T112~T118 保持空档作为 v2/v3 分界缓冲）：

```
T100→T119   T101→T120   T102→T121   T103→T122   T104→T123
T105→T124   T106→T125   T107→T126   T108→T127   T109→T128
T110→T129   T111→T130   T112→T131   T113→T132   T114→T133
T115→T134   T116→T135   T117→T136   T118→T137
```

已同步：`plan_v3`（§2 总览 + 19 张任务卡 + §4 门槛引用 + 修订记录）、`traceability.md` §7bis、
`ADR-013~016` 的「关联」行、`v3-spec-gate.md` G-D6/G-D8。

## 后果

### 正面
- 全仓 T 编号**唯一**，`git log`/审计/回滚不再歧义
- 「一个 T 一条 commit」铁律在 v2/v3 并存的窗口期可执行

### 负面 / 代价
- 旧编号的**历史引用**（本 ADR 之外的审计、聊天、笔记）需按映射对照
- 若 v2 将来再扩 Wave（T112+），须遵守「v2 编号 ≤ T118，v3 编号 ≥ T119」的分界

## 被否决的备选方案

| 备选 | 否决理由 |
|---|---|
| **保留 T100~T118，commit 消息加 `V3-` 前缀**（如 `V3-T103`） | 破坏「T 号全局唯一」的心智模型；审计脚本 `grep -o 'T[0-9]*'` 会漏 `V3-T` 形态；两套计划仍同号 |
| **只顺延撞号的 12 个（T100~T111），T112~T118 不动** | 编号中段跳号（…T128, T129, T112…），G-D6「编号连续无缺号」直接 FAIL；阅读易错 |
| **v3 改用独立编号空间（V3-1~V3-19）** | 与 AGENTS.md / plan_v2 的 T 号体系双轨，任务卡、traceability、gate 全部要双写；且 T 号在 CI 脚本中已被多处按 `T[0-9]+` 提取 |
| **等 v2 全部完结再决定** | v2 Wave 12 已收尾，窗口期只有 v3 实施期；越晚改引用面越大 |

## 关联证据

- v2 计划 §5 汇总表：Wave 9~12 = T99/T100/T102/T103 + T104~T109 + T110/T111（`docs/client/code_implementation_plan_v2.md`）
- v3 计划 §2：19 任务初稿 T100~T118（本 ADR 实施前状态）
- 2026-10-24 实查：`main` 上 `git log --oneline` 存在 `#34 T103`、`#37 T104-T109`、`#38 T110`、`#39 T111` 等 commit，撞号已在真实历史中出现
