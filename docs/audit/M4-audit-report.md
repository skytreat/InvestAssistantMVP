**审计日期**：2026-11-07
**审计基准**：`docs/audit/proposal-strategy-backtest-framework.md` §7（参数空间）/ §8.4（防过拟合）/ §10（预算）

**运行环境**：本机 Windows，Node 25.8.1，串行执行（并发 1）
**结论（先给）**：**不改默认参数**。训练段最优组在样本外跑输默认参数 40.39 个百分点，且第二折样本外为负；`lookbackDays` 只有极窄有效区，按稳定性规则判为不可用。

## 1. 样本切分：两折扩张式 walk-forward

| 折 | 训练段 | 测试段 |
|---|---|---|
| fold1 | 2023-01-01 ~ 2023-12-31 | 2024-01-01 ~ 2024-12-31 |
| fold2 | 2023-01-01 ~ 2024-12-31 | 2025-01-01 ~ 2025-12-31 |

- 全区间一次连续回测 2023-01-01 ~ 2025-12-31，**样本内 / 样本外指标由同一份净值按日期切片派生**，不额外重跑。
- 扩张式（expanding）而非滚动固定窗口：只有 3 年样本，固定窗口会把训练段压到 1 年；11 个待搜参数对约 250 个交易日，维度灾难更严重。
- 隔离是硬校验，不是注释：`assertFoldsIsolated()` 在启动时断言 `trainEnd < testStart`、两折测试段互不重叠，失败立即终止（避免跑到一半才发现泄漏）。

### 1.1 为什么训练段只能从 2023 起算

**股票池是按 2026 年的流动性（`divisor=20000` / `topN=300`）选出的固定池。** 把训练段前移到 2020：

1. **后视偏差**：池子的入选资格来自 2026 年的成交额与上市状态，2020 年时这些标的的构成是「未来信息」。前移等于用 2026 的眼光挑出 2020 年的赢家再回测，收益会被系统性抬高。
2. **口径漂移**：固定池是 M1/M3 锁定项（与 `FIXED_PARAMS` 同源）。为了多两年样本去改池子口径，等于同时改掉基线，前后结果不可比。
3. **数据覆盖**：2023 年之前部分标的的复权/除权数据完整度未经本轮验证，混入会污染训练段指标。

因此 **起点固定 2023，用户已明确否决前移到 2020**。代价是训练段只有 1~2 年，也是后续所有「过拟合嫌疑」判定的背景。

## 2. 搜索空间与预算

|---|---|---|
| `holdingsNum` | 1, 2, 3 | ✅ |
| `lookbackDays` | 15, 20, 25, 30, 35, 40 | ✅ |
| `r2Threshold` | 0.1 ~ 0.8 step 0.1 | ✅ |
| `maLookback` | 5, 10, 15, 20, 25, 30 | — |
| `maThreshold` | 0.97, 0.99, 1.0, 1.01, 1.03, 1.05 | — |
| `volumeRatioThreshold` | 1.0, 1.2, 1.5, 1.8, 2.0, 2.5, 3.0 | ✅ |
| `volumeLookback` | 3, 5, 10, 15, 20, 30 | — |
| `lossThreshold` | 0.90 ~ 1.00 step 0.01 | ✅ |
| `scoreThresholdRatio` | 0.50 ~ 1.00 step 0.05 | ✅ |
| `maxWeakDays` | 5, 10, 15, 20, 30, 40, 60 | — |
| `stopLossThreshold` | 0.80 ~ 1.00 step 0.02 | — |

全组合数 **2,028,571,776**（≈2.03×10⁹），不可穷举，只能确定性抽样。

不搜的参数：`divisor=20000`、`topN=300`、`minScore=0`、`maxScore=5`、`defensiveEtf=sh511880`。它们决定**时点池**或保护性边界，属 M1/M3 锁定口径，不是择时参数。

> 注意：默认值 `stopLossThreshold=0.95` **不在网格内**（0.80 起 step 0.02 只落在偶数分位）。基线仍按默认值 0.95 实跑，网格与基线在此项上不同源，这是有意的——避免把默认值强行塞进网格造成「基线即候选」。

### 2.2 实试次数与预算

| 阶段 | 试次数 | 说明 |
|---|---|---|
| baseline | 1 | 默认参数，作为参照与细搜中心之一 |
| coarse | 200 | 全空间确定性随机抽样（`--coarse 200`） |
| fine | 189 | 以粗搜 Top10%（20 个）∪ 基线为 **21 个中心**，每中心 9 组的单参数邻域细化（`--fine 200` 按中心数均分） |
| stability | 11 | 最优组的核心参数上下邻档（**不计入汇总统计**） |
| **合计落库** | **401** | `bt_trial` 行数；计入汇总的试次 390（合格 236） |

### 2.3 目标函数

`selectionScore = mean(fold1.train.CAGR, fold2.train.CAGR)` —— **只用训练段**，样本外数据不参与选择。

报告主指标为 `oosMeanCagr = mean(fold1.test.CAGR, fold2.test.CAGR)`，只用于评估，不参与排名。

### 2.4 硬约束（任一不满足即 `eligible=false`，不进入排名）

1. 训练段最大回撤 ≤ 基线同段 × 1.2；
2. 训练段平仓回合 ≥ 30（样本太少则指标无意义）；
3. 全区间平均暴露 ≤ 1.0（禁止隐含杠杆）。

### 2.5 稳定性判定

对最优组的每个**核心参数**，只动这一个参数取上下邻档，复跑其样本外 CAGR：

- 邻居中位数 ≥ 中心值 × 70%，且上下两侧跌幅均 < 30% ⇒ `robust`；
- 任一侧缺失 ⇒ `insufficient`（无法判定）；
- 否则 ⇒ `unusable`（该参数不可用，**不因单点高收益而采纳**）。

必须「只动一个参数」的邻居——同时动两个参数得到的高点不构成稳定性证据。

## 4. 稳定性曲面与参数迹象

中心组 = `fn-0388`（样本外 33.16%）。

| 参数 | 中心值 | 下邻档 | 上邻档 | 邻居中位数 | 判定 |
|---|---|---|---|---|---|
| `lookbackDays` | 25（33.16%） | 20 → 45.11% | 30 → **−2.49%** | 21.31% | **unusable** |
| `holdingsNum` | 1（33.16%） | 无（1 已是下界） | 2 → 61.50% | 61.50% | insufficient |
| `r2Threshold` | 0.4（33.16%） | 0.3 → 33.65% | 0.5 → 34.12% | 33.88% | robust |
| `lossThreshold` | 0.96（33.16%） | 0.95 → 23.98% | 0.97 → 33.63% | 28.80% | robust |
| `scoreThresholdRatio` | 0.95（33.16%） | 0.9 → 42.20% | 1.0 → 30.59% | 36.40% | robust |
| `volumeRatioThreshold` | 1.5（33.16%） | 1.2 → 32.97% | 1.8 → 67.95% | 50.46% | robust |

### 4.1 `lookbackDays` 只有窄有效区

25 是**尖峰**，不是平台：20 → 45.11%，30 → **−2.49%**。上侧跌幅 107.50% 远超 30% 阈值，邻居中位数也只有中心的 64.3%。

⇒ **该参数不可用**。即便有人想「取 20 换更高收益」，20 与 25 之间没有中间档可验证，无法排除 20 也是尖峰。这是本次寻优中最强的负面结论。

### 4.2 `r2Threshold=0.5` 的轻微迹象

0.5 → 34.12%，比中心（0.4）高 0.96pp；0.3 → 33.65%。三档连成平台，`robust` 成立，**方向一致但幅度极小（<1pp）**，落在抽样误差量级内。

Top10 候选里有 3 组用 0.5（`fn-0383` 71.30%、`fn-0387` 72.28%、`fn-0227` 32.52%），但训练段排名分别第 7、第 9、第 8，且这三组的其他参数差异较大。**不足以支持改默认 0.4。**

### 4.3 `holdingsNum=2` 的轻微迹象

`holdingsNum=2` 的样本外 61.50%，比 1 高 85.46%；Top10 候选里 `fn-0386`（2 只，62.65%）、`c-0053`/`fn-0209`（2 只，37.05%）同向。但：

- 1 已是网格下界，**没有下邻档** ⇒ 无法判定是否尖峰，规则判 `insufficient`；
- `holdingsNum` 同时改变换手与单票集中度，**不是纯参数微调**，跨折可比性弱。

⇒ 只作为**观察项**记录，不改默认值（默认 `holdingsNum=1`）。

## 5. 多重检验披露

本次共比较 **390 个计入汇总的试次（合格 236）**，其中 baseline 1 + coarse 200 + fine 189。核心披露：

| 披露项 | 实测值 |
|---|---|
| 样本外均值 CAGR 中位数 | 19.99% |
| 样本外均值 CAGR 最优 | 80.66% |
| **最优 − 中位差** | **60.66 个百分点** |
| 基线样本外 CAGR | 73.55% |
| 训练段相对基线 | **+14.25pp** |
| 样本外对应差值 | **−40.39pp** |

- 60.66pp 的「最优−中位」落差**主要是 best-of-N 选择偏差**，不是策略能力。任何「取最高那组」的解读都会系统性偏乐观。
- 训练段 +14.25pp 在样本外变成 −40.39pp，**符号反转**。这是过拟合的典型形态：训练段越优，样本外越差。
- 基线本身的样本外 73.55% 高于最优候选的 33.16%，**寻优没有产生正增量**。

Top10 的样本外跨度 10.80% ~ 72.28%，**排名与样本外表现无单调关系**（第 10 名 10.80%，第 7 名 71.30%）。这进一步说明训练段排名不具预测力。

## 7. 复现方式

```bash
# 全量 sweep（本次实测所用命令）
npx tsx apps/backend/src/services/backtest/cli.ts sweep \
  --sweep-id m4-full-v1 \
  --seed 20261107 \
  --mode full \
  --coarse 200 \
  --fine 200 \
  --db data/backtest-m4.db \
  --report data/m4-full-v1.json
```

- **`--seed` 规则**：`trialSeed(baseSeed, index) = hash32("<baseSeed>:<index>")`（FNV-1a 32bit），再由 `mulberry32` 抽样。种子**只由 `--seed` 与试次序号决定，与 `sweepId` 无关** ⇒ 同一 `--seed` 重跑任何 sweep 得到逐位一致的参数序列（pilot 复现已验证 diff=0）。
- 参数网格的**声明顺序参与抽样**：改动 `SEARCH_GRID` 顺序会改变同 seed 的序列。
- 产物（**均不入库**，`data/` 已被 `.gitignore` 忽略）：`data/backtest-m4.db`（`bt_run` / `bt_trial` / `bt_skipped`）、`data/m4-full-v1.json`。
- 本次结果的关键数字已全部写入本文正文，无需依赖上述文件即可核对。

## 8. 与 v5.2 Python 原版的已知口径偏差

本项目为 Node/TypeScript 重写，**不是逐行移植**。已知偏差（引自 `docs/audit/wufu-etf-rotation-v5.2-feasibility-2026-11-06.md`）会影响与 Python 原版的绝对收益可比性：

| 维度 | v5.2 Python 原版 | M4 实现 | 影响 |
|---|---|---|---|
| **决策时点** | 盘中 13:10 决策 + 盘中成交 | **T-1 收盘决策 + T 开盘成交**（方案 A，无前视） | 这是**刻意分歧**：13:10 决策需分钟 K 线，与 AGENTS.md「分钟 K 线 / 盘中实时信号」Out-Scope 硬冲突 |
| 13:10 价格 | `last_price`（分钟快照） | 用 T-1 收盘 / T 开盘 | 13:10 价相对收盘的偏差代理 `|(H+L)/2 ÷ C − 1|`：均值 **0.766%**，最大 **10.3%**；进入 25 日回归末点（`W=4`）后单只 score 变动通常 **<2%** |
| 分时量 | 13:10 前分时量投影全日 | 用**全日成交量**替代 | 真实 U 型分布下量比被**低估约 10–20%（估算）**，方向是**多放行标的**（更宽松） |
| 涨跌停 | 真实 `high_limit/low_limit` | `preclose × (1±10%)` | 忽略 ST/科创/创业板的差异化涨跌幅 |
| 停牌 | `paused` 字段 | 「缺 bar ∪ 零量」推断 | 边界情况可能误判 |
| ETF 名称 | 历史快照 | 当前快照 | 名称类判定存在事后信息 |
| 上市日 | 真实上市日 | 首根 bar 日期 | 新股早期数据可能缺失 |
| 分钟止损 | 有 | **无**（日线级） | 与 Out-Scope 一致 |

综合口径：**日线级等效度约 88–92%**（路径口径），规则对照口径 100%。因此：

- 本文所有数字**只在 M4 自身的口径内可比**（基线与候选同口径，故 §3 的相对结论成立）；
- **不应把 M4 的绝对 CAGR 与 v5.2 Python 原版的历史回测直接对比**，13:10 盘中决策本身含约 2 小时前视，属系统性偏乐观。

## 9. 结论

**不改默认参数。**

1. **样本外不优**：训练段最优 `fn-0388` 样本外 33.16%，默认参数 73.55%，**落后 40.39pp**；且两折测试段均未跑赢基线，fold2 测试为 **−34.33%**。
2. **样本内提升不延续**：训练段 +14.25pp → 样本外 −40.39pp，符号反转，符合过拟合特征；分年度看是逐年恶化（2023 +23.36pp → 2024 −24.97pp → 2025 −55.81pp）。
3. **`lookbackDays` 不可用**：25 是尖峰，30 直接掉到 −2.49%，上侧跌幅 107.50%，判 `unusable`。任何「取 20 或 25 更好」的结论都不成立。
4. **`r2Threshold=0.5` 与 `holdingsNum=2` 只有轻微迹象**：前者 robust 但幅度 <1pp；后者因缺下邻档判 `insufficient` 且不是纯参数微调。**均不足以改动默认值。**
5. **多重检验偏差显著**：390 个试次里最优与中位差 60.66pp，属 best-of-N 选择偏差，不能当作可获取的收益。

### 9.1 明确不做的改动

- 不改 `WUFU_ROTATION_DEFAULTS` 任何默认值；
- 不改固定池口径（`divisor` / `topN`），不回填 2020 年样本；
- 不改策略逻辑（本次任务范围明确排除）；
- 不因为 `fn-0383` / `fn-0387` 的 71%+ 样本外高点而重排参数——它们是训练段第 7、第 9 名，属事后挑选。

### 9.2 后续若仍要做参数寻优

- 样本量是硬瓶颈：3 年、2 折，训练段最多 2 年。继续加大试次只会放大选择偏差，不会提高可信度。
- 若先补齐 2026 年数据形成**真正的样本外留出段**（不参与任何一轮选择），再评估参数才有意义。
- 在此之前，默认参数即为当前证据下的最优选择。
