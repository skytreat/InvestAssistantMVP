## 2. G-PE5 —— §13.16 实测

### 2.1 候选筛选（实测，非推测）

真库 `v_etf_qfq` 共 **2930 只** ETF（1993-08-20 ~ 2026-10-22）。候选与池内 A 股腿的日收益相关性
（2019-01-02 ~ 2026-10-22，n=1890）：

| 候选 | 类型 | vs `sh510300` | vs `sh510500` | 数据起 |
|---|---|---|---|---|
| `sh511260` | 十年国债 | **−0.278** | −0.255 | 2017-08-24 |
| `sh511010` | 国债 | **−0.257** | −0.223 | 2013-03-25 |
| `sh511880` | 货币 | −0.183 | −0.184 | 2013-04-18 |
| `sh511990` | 货币 | −0.120 | −0.121 | 2013-01-28 |

债券腿与 A 股池**负相关**，分散度高于黄金腿（+0.07~+0.19）——理论上应显著降 MDD。

### 2.3 「债券腿从未入选」的取证

不靠推测——直接统计扩池组的**实际成交标的**：

```console
TRADED ["sh510300","sh510500","sh513000","sh513100","sh513500","sh518880","sz159915"]
TRADES 4657
```

`sh511260` / `sh511010` **一笔未成交** ⇒ 扩池不是「效果小」，而是**根本进不了候选**。

根因：扩展标的走**同一套 L1 过滤链**（MA 多头排列 + 主槽动量在区间内 + 日涨跌 ±5% + `soft` 基准门槛
`primary >= benchmarkPrimary`），债券 ETF 的 WSM 动量长期贴近 0 或为负，几乎不可能 ≥ 沪深300 动量
⇒ 与 §12.3「把 `511880` 加进 7 只池无效（过不了 MA+动量过滤）」的预警一致。

### 2.4 判定

**B1/B2 路径否决**。负相关的债券腿**进不了同一套动量过滤**——这是**信号层与资产层的错配**，
不是参数问题；组合层补丁（扩池 + 防御回退）解决不了。

若要真正用上低相关资产，需**为防御腿单独设计一条不依赖动量的入场规则**
（如「基准动量转负 → 切债券」），那是**新的策略语义**，须另立 ADR + 新 spec，不在本次范围内。
