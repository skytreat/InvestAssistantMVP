# 个人投资助手 — 产品需求文档（PRD）

**版本：V1.0**
**日期：2026-10-14**
**文档定位：本文件从产品视角出发，回答「谁在用、为什么用、体验如何」。所有业务规则的细节参见同目录下的 Requirements_simplified.md。**

---

## 1. 产品概述

### 1.1 用户痛点

个人 A 股 / ETF 投资者面临以下核心痛点：

| 痛点 | 具体表现 |
|------|---------|
| **记账混乱** | 手动在 Excel 或证券账户间切换，手续费口径不一致，移动加权成本算不准，分红送转经常遗漏 |
| **收益看不清** | 证券 App 只显示现价市值，不知道真实收益率（含分红现金流入）；不同账户的成本口径无法统一 |
| **行情数据碎片化** | 通达信/雪球/同花顺数据来源不统一，前复权/后复权切换繁琐，无法做本地分析 |
| **策略执行无依据** | 看了很多 RSI/MACD 教程，但没有一个工具能在收盘后自动给自己的自选 + 持仓标的跑一遍策略信号 |
| **选股靠感觉** | 全市场 5000+ 标的，一个个翻不现实，想按「换手率 > 5% 且 市值 < 50 亿」这种条件筛选没有趁手的工具 |
| **交易复盘缺位** | 买了卖了就算了，没有系统记录交易理由、是否符合策略、是否止损，无法归因总结 |
| **数据质量无法验证** | 通达信/雪球数据偶尔出错（除权日错乱、价格跳变），无法自行校验发现 |

### 1.2 产品愿景

让个人投资者用一个浏览器就能完成：**精准记账 → 实时看持仓成本 → 自动跑策略信号 → 全市场条件选股 → 系统复盘归因** 的完整闭环。

核心信念：**正确的数据 + 稳定的系统 + 可扩展的策略框架，比复杂的功能更重要。**

### 1.3 产品边界

| 做 | 不做 |
|----|------|
| 交易记录、持仓聚合、成本核算 | 自动下单、对接实盘券商 |
| 日线行情跟踪、策略信号监控 | 盘中实时行情、分钟级信号 |
| 全市场条件选股 | 预测股价、荐股推荐 |
| 复盘归因、收益统计 | 替用户做投资决策 |
| 手动记账 + 自动除权导入 | 微信小程序、桌面独立程序 |
| 插件化策略框架（可扩展） | 复杂量化回测、高频策略 |

### 1.4 目标用户

- **A 股 / ETF 个人投资者**，持仓 2-20 只标的
- **有技术分析基础**，听过 RSI/MACD、前复权/后复权
- **希望系统化管理交易记录**，而不是只看证券 App 的现价
- **桌面 + 手机都需要访问**（办公室用桌面看细节，通勤用手机看概览）

## 2. 用户画像

### 画像 A：日常投资者（普通用户）

| 维度 | 描述 |
|------|------|
| **基本信息** | 30-50 岁，个人投资者，持仓 5-15 只 A 股/ETF |
| **典型行为** | 每日 8:30-9:30 看美股中概股 → 14:30 收盘前调整 → 15:00 后复盘 |
| **核心诉求** | 记账精准、持仓一目了然、策略信号自动推、收益透明 |
| **使用频率** | 每周 3-5 次，每次 10-30 分钟 |
| **技术能力** | 能操作 Web 应用，对「前复权」「RSI 超买」等概念熟悉 |
| **设备偏好** | 主要桌面浏览器（Chrome），偶尔手机浏览器 |
| **典型担忧** | 数据安全、记账错误、策略信号不准 |

### 画像 B：进阶投资者（普通用户）

| 维度 | 描述 |
|------|------|
| **基本信息** | 28-40 岁，有独立策略体系，持仓 15-30 只 + 候选池 30+ |
| **典型行为** | 每日收盘后跑一遍信号 → 每周六深度复盘 → 每月调整策略参数 |
| **核心诉求** | 插件化策略引擎可扩展、选股功能强大、复盘能归因 |
| **使用频率** | 每日使用，每次 30-60 分钟 |
| **技术能力** | 能看 K 线副图，会调参数，希望自定义策略插件 |
| **设备偏好** | 桌面为主 |
| **典型担忧** | 数据校验不通过、插件执行超时、服务器宕机 |

### 画像 C：管理员（产品所有者）

| 维度 | 描述 |
|------|------|
| **基本信息** | 通常与画像 A/B 是同一人（自己搭自己用）或最资深的用户 |
| **核心诉求** | 行情数据可信、备份可靠、异常可追踪、服务不停机 |
| **典型行为** | 每日收盘后看校验结果 → 偶尔手动触发行情更新 → 定期备份恢复测试 |
| **技术能力** | 能看日志，理解 PASS/WARN/ERROR 含义 |

## 3. 用户故事

### 3.1 交易记账

| # | 用户故事 | 价值 |
|---|---------|------|
| T1 | 作为投资者，我**手动记录买入/加仓/减仓/清仓**，并填写操作理由，这样我日后能回忆当时的决策 | 强制记录决策依据 |
| T2 | 作为投资者，系统**自动导入分红/送股/转增交易**，我不用手动去加这些非交易性变动 | 避免遗漏，保证成本准确 |
| T3 | 作为投资者，我可以**手动补充系统遗漏的分红/送股/转增**，系统自动帮我填好操作理由 | 兜底机制，操作省力 |
| T4 | 作为投资者，我**减仓/清仓时系统自动校验不超持仓**，避免写出负持仓脏数据 | 数据质量安全网 |
| T5 | 作为投资者，所有交易**永久留痕不可物理删除**，支持软删除标记（隐藏但可恢复或审计查看），保证记账可追溯 | 审计友好，支持错误修正 |
| T6 | 作为投资者，每笔交易可以**事后填写复盘总结、是否符合策略（三态：是/否/未标记）、是否止损（三态：是/否/未标记）** + 备注 | 复盘归因，积累经验 |

### 3.2 持仓管理

| # | 用户故事 | 价值 |
|---|---------|------|
| H1 | 作为投资者，我能看到**每只持仓的移动加权成本、现价、盈亏、收益率、仓位占比** | 一眼看清持仓全貌 |
| H2 | 作为投资者，**买入手续费计入成本、卖出手续费抵扣盈亏但不影响剩余成本**，口径与证券账户一致 | 成本核算精准 |
| H3 | 作为投资者，**送股/转增自动增加数量、均价自动稀释不变** | 除权后成本连续 |
| H4 | 作为投资者，**分红不影响持仓成本、现金流入单独计入实际收益** | 成本与收益分离 |

### 3.3 行情与策略

| # | 用户故事 | 价值 |
|---|---------|------|
| M1 | 作为投资者，我能看到**前复权日线 K 线图**，MA/MACD/RSI/KDJ 等副图指标可切换 | 技术分析必备 |
| M2 | 作为投资者，我**改 RSI 参数时图表即时重绘**，不用刷新页面、不用等服务器 | 交互式探索体验 |
| M3 | 作为投资者，我在**K 线上看到策略信号标记**（买入绿▲/卖出红▼），知道什么时候触发的 | 信号可视化 |
| M4 | 作为投资者，**每日收盘后系统自动跑一遍自选 + 持仓标的的策略信号**，第二天打开就能看到 | 自动化闭环 |
| M5 | 作为进阶投资者，我可以**安装自己写的策略插件**，和内置 RSI/MACD 一样生效 | 可扩展 |
| M6 | 作为投资者，**信号状态机只在状态切换瞬间发一次信号**，不刷屏、不重复 | 信号干净 |
| M7 | 作为投资者，**停牌日策略自动维持状态**，不会发假信号 | 状态稳健 |

### 3.4 收益统计

| # | 用户故事 | 价值 |
|---|---------|------|
| R1 | 作为投资者，复盘页可以**切换价格收益率 vs 实际收益率**，前者看技术波动，后者看真实盈亏 | 双口径满足不同场景 |
| R2 | 作为投资者，复盘页展示**胜率、盈亏比、月度/季度/年度收益曲线** | 量化评估策略效果 |
| R3 | 作为投资者，复盘页可以**按交易类型/是否止损/是否符合策略筛选归因** | 找到赚钱/亏钱的模式 |
| R4 | 作为投资者，系统**每日收盘后自动生成资产快照**（同时包含价格收益率和实际收益率双口径），用于收益曲线的历史追踪 | 收益趋势完整可追溯 |

### 3.5 选股与候选池

| # | 用户故事 | 价值 |
|---|---------|------|
| S1 | 作为投资者，我可以**按行业/概念/市值/换手率/ST 状态等条件筛选**全市场标的 | 缩小关注范围 |
| S2 | 作为进阶投资者，我可以**用筛选类策略插件做条件选股**，动态参数表单自动渲染 | 插件化选股 |
| S3 | 作为投资者，我可以把**选股结果一键全部加入候选池**，不用一个个点 | 批量操作 |
| S4 | 作为投资者，候选池**手动加标的**时**基准价固化为加入日收盘价** | 跟踪有基准 |
| S5 | 作为投资者，**候选池迁移自选时可选复用基准价或用现价**；MVP 迁移操作**只在候选记录上打标记，不会自动创建自选关联**（用户需手动从候选池加入自选）| 灵活迁移，行为明确不混淆 |

### 3.6 数据质量与运维

| # | 用户故事 | 价值 |
|---|---------|------|
| D1 | 作为投资者，我可以在设置页看到**12 项数据校验结果**（PASS=绿/WARN=黄/ERROR=红/SKIP=灰 四色），SKIP 表示该外部数据源今日不可用已自动跳过（如跨源校验被限流）| 知道数据可信，理解校验降级 |
| D2 | 作为管理员，我可以**手动触发行情更新**，立即跑完整流程 | 快速修正数据问题 |
| D3 | 作为管理员，**WARN 级别校验自动触发补跑**，ERROR 记录告警 | 自愈闭环 |
| D4 | 作为管理员，我可以**手动备份 + 手动恢复验证** | 备份可靠 |
| D5 | 作为管理员，**首个注册用户自动成为管理员**，bootstrap 简单 | 零配置启动 |

## 5. 交互与体验要求

### 5.1 响应式布局

| 断点 | 布局 |
|------|------|
| 桌面端（≥ 1024px） | K 线图 + MA/MACD/RSI/KDJ 多副图并排；持仓卡片多列；信号标记在主图 + 副图 |
| 手机端（< 768px） | K 线图主图 + 副图 Tab 切换（一次看一个）；持仓卡片单列；信号标记简化显示 |
| 平板端（768-1024px） | 中间态，副图 Tab 切换，持仓 2 列 |

### 5.2 K 线图交互

| 要求 | 说明 |
|------|------|
| 默认前复权 | 用户可切换不复权/前复权/后复权 |
| 主图叠加 MA | MA(5/10/20/60) 默认显示，可隐藏 |
| 副图切换 | MACD / RSI / KDJ 可切换显示；桌面端可并排多副图 |
| 策略信号标记 | 买入绿▲/卖出红▼，鼠标悬停显示方向 + 强度 + 指标明细 |
| 参数实时生效 | 改 RSI period 或超买阈值 → **图表**即时重绘，零网络请求（指标在前端计算）。⚠️ **2026-10-17 澄清**：此处**不含信号** —— 信号由后端插件引擎按 17:02 调度批量判定并落库，改阈值后**在下一次调度或手动触发时生效**，不做即时重算（信号是「每日批量判定」的产物，即时重算与其语义不符）|
| 时间范围切换 | 日 K / 周 K / 月 K（MVP 仅日线，周/月基于日线聚合） |
| 十字光标 + 价格悬浮 | K 线图上拖动十字光标，悬浮窗显示当日 OHLCV + 指标值 + 信号标记 |

### 5.3 持仓页交互

| 要求 | 说明 |
|------|------|
| 总资产卡片 | 顶部大卡片：总资产、总盈亏、总收益率（颜色区分正负）、双口径切换 |
| 资产组成饼图 | 股票 + ETF 按市值分布，支持点击下钻到持仓列表过滤 |
| 持仓卡片列表 | 每只标的：代码 + 名称、现价、持仓数量、移动加权成本、盈亏、收益率、仓位占比（进度条） |
| 快速操作 | 每张持仓卡片右侧【买入】【卖出】快捷按钮 → 弹出交易录入弹窗 |
| 筛选排序 | 按盈亏金额/收益率/仓位占比排序；按标的类型/行业过滤 |

### 5.4 交易录入弹窗

| 要求 | 说明 |
|------|------|
| 交易类型选择 | 顶部 Tab 切换：买入 / 加仓 / 减仓 / 清仓 / 除权补充 |
| 操作理由 | 买入/加仓/减仓/清仓时必填（UI 不允许空值）；除权补充时系统固化置灰 |
| 实时预估 | 输入买入数量 + 价格 + 手续费 → 实时显示预估新均价；减仓超持仓 → 红色禁用提交 |
| 标签快捷填充 | 预设标签按钮（如「策略触发」「止损」「抄底」），一键填入操作理由 |
| 除权补充表单 | 除权日、分红金额/送转比例等数值字段可编辑；操作理由自动固化 |
| 系统 vs 人工标签 | 自动导入的交易在持仓列表/复盘列表中以绿色「系统导入」标签展示；手动补充以灰色「人工补充」标签展示 |

### 5.5 复盘页交互

| 要求 | 说明 |
|------|------|
| 双口径切换 | 顶部 Tab：价格收益率 / 实际收益率，默认实际收益率 |
| 收益曲线 | 月度/季度/年度切换；悬浮显示具体数值 |
| 胜率 + 盈亏比卡片 | 大卡片展示；盈亏比 = 平均盈利 / 平均亏损 |
| 交易列表 | 可按交易类型 / 是否止损 / 是否符合策略 / 日期范围筛选 |
| 列表标签颜色 | 未复盘（灰）/ 系统信号触发（绿）/ 主观决策（橙）/ 止损（红）叠加显示 |
| 复盘编辑弹窗 | 点击交易记录 → 弹窗填写复盘总结、是否符合策略、是否止损、备注；**三态字段默认未标记（null），显示灰色"未标记"文字**，点击可切换为"是"（绿色）/"否"（红色）|

### 5.6 选股页交互

| 要求 | 说明 |
|------|------|
| 公共过滤 | 标的类型（股票/ETF）、排除 ST、成交额下限、行业选择 |
| 筛选插件下拉 | 动态加载可用筛选类插件，选中后自动渲染参数配置表单 |
| 一键运行 | 按钮触发，结果 ≤ 100 条，支持分页 |
| 批量加入 | 【全部加入候选池】按钮；或逐只选中后加入 |
| 结果表格 | 标的代码 + 名称、筛选参数（如换手率、市值）、现价、收益率 |

### 5.7 管理员界面

| 要求 | 说明 |
|------|------|

### 5.9 安全与合规 UX

## 7. MVP 迭代顺序（价值驱动）

Phase 边界原则：**每 Phase 交付一个可运行的独立闭环**，Phase 之间线性依赖，不抢跑。各 Phase 详细交付物清单参见同目录下 [Requirements_simplified.md 第 9 节](Requirements_simplified.md#9-mvp-迭代规划4-phase每-phase-交付可运行闭环)。

### Phase 1：空壳底座

> **用户价值**：用户可以注册/登录，管理员能看到行情数据是否就绪。

**对应用户旅程**：首次注册 → 登录。

| 用户/管理员感知 |
|---------------|
| 能注册/登录，首用户自动成为管理员 |
| 行情数据初始化完成 |
| 定时流程（行情更新 + 备份）能跑通 |
| 插件引擎空框架就绪 |

### Phase 2：后端业务闭环

> **用户价值**：用户能完整记账 + 看持仓成本，策略引擎能生成信号并持久化。

**对应用户旅程**：记账 → 看持仓成本 → 复盘（基础）。

| 用户/管理员感知 |
|---------------|
| 7 种交易类型全部可写 |
| 持仓成本/盈亏实时聚合 |
| 分红送转增自动入账 |
| 每日收盘后自动跑策略信号 |

### Phase 3：完整可交互产品

> **用户价值**：完整 Web 前端可用，K 线图有副图和信号标记，复盘有双口径。

**对应用户旅程**：日常记账 → 看 K 线 → 看信号 → 复盘归因。

| 用户/管理员感知 |
|---------------|
| 响应式前端完整可用（持仓/K线/复盘/设置） |
| K 线图 + 交互式指标参数调整 |
| 策略信号在 K 线图上可视化标记 |
| 复盘双口径切换 + 4 字段编辑 |
| 收盘后全流程自动化 |

### Phase 4：完整 MVP 验收

> **用户价值**：全市场选股 + 候选池可用，管理员功能齐全，所有验收项通过。

**对应用户旅程**：选股 → 加入候选池 → 迁移自选。管理员：看校验 → 手动更新 → 备份恢复。

| 用户/管理员感知 |
|---------------|
| 全市场条件选股可用 |
| 候选池 + 迁移自选 |
| 12 项校验仪表盘 + 管理员手动触发 |
| MVP 验收走查全部通过 |

## 8. 附录：术语表

| 术语 | 定义 |
|------|------|
| 前复权 | 除权除息后，对历史价格向下调整，使价格连续 |
| 后复权 | 除权除息后，对当前价格向上调整，使历史价格不变 |
| 移动加权平均成本 | 每次买入后重新计算平均成本：新均价 = (原持仓 × 原均价 + 买入数量 × 买入价 + 买入手续费) / (原持仓 + 买入数量) |
| RSI | 相对强弱指标（Relative Strength Index），衡量超买超卖 |
| MACD | 指数平滑异同移动平均线，衡量趋势方向和强度 |
| KDJ | 随机指标，衡量超买超卖 |
| 除权除息（gbbq） | 公司分红、送股、转增等导致股权变动的事件 |
| 策略插件 | 实现了统一接口的独立计算模块，接收日线序列，输出信号 |
| 候选跟踪池 | 独立于自选的跟踪列表，用于评估选股策略胜率 |
| ST 状态 | 连续亏损上市公司的特别处理（Special Treatment） |
