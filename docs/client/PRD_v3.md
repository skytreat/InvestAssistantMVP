## 1. V3 的用户旅程总览

V3 覆盖 7 个能力域，对应 3 条主线：

```
主线 A：把账对上 ────────────────────────────────────────────
  ① 导入券商文件  →  ② 看对账报告  →  ③ 补录缺失  →  ④ 按券商看持仓与收益

主线 B：让策略可评估 ───────────────────────────────────────
  ⑤ 策略配置与信号  →  ⑥ 信号复盘  →  ⑦ 策略有效性评估

主线 C：替代 Excel 复盘 ─────────────────────────────────────
  ⑧ 交易对视图  →  ⑨ 复盘记录  →  ⑩ 组合风控体检
```

**贯穿全局的改动**：标的输入（免前缀 + 联想）覆盖所有录入入口。

## 2. 全局：标的输入组件（S1）

### 2.1 组件规格

所有录入入口（交易录入 / 复盘筛选 / 候选池 / 自选 / 持仓筛选）**共用同一个组件**。

> **基线说明**：Wave 4 的 T68 已把联想抽出为独立组件 `apps/frontend/src/components/SymbolAutocomplete`，
> 交易录入页（T68）已在使用。本任务是在**该现有组件上增强**，不是新建。

```
┌──────────────────────────────────────────────┐
│  600519                          [×]           │  ← 裸 6 位即可，不需要打 sh/sz
├──────────────────────────────────────────────┤
│  sh600519  贵州茅台          沪A · 股票        │  ← 代码 + 名称 + 市场/品种
│  sz000001  平安银行          深A · 股票        │
│  ─────────────────────────────────────────    │
│  sh511990  华宝添益          沪A · ETF · 现金类 │  ← 现金类标识
├──────────────────────────────────────────────┤
│  ↑↓ 选择   Enter 确认   Esc 关闭                │
└──────────────────────────────────────────────┘
```

| 项 | 规格 | 状态 |
|---|---|---|
| 输入 | 接受裸 6 位 / 带前缀 / 中文名 / 拼音首字母 | ✅ |
| 结果列表 | **代码 + 名称 + 市场 · 品种**，现金类加「现金类」标签 | ✅ |
| 键盘 | ↑↓ 移动、Enter 确认、Esc 关闭 | ✅ |
| 提交 | **自动补全前缀**（用户不需要从列表里选） | ✅ |
| 唯一命中 | 裸 6 位唯一命中 → **直接填入并关闭列表** | ✅ 已定：唯一命中时自动确认，不等用户按 Enter |
| 多命中 | 同 6 位命中多条 → 展示列表让用户选 | ✅ |
| 名称缺失 | 显示代码 + 空名称，**不报错** | ✅ |
| 防抖 | 输入停止 **200ms** 后才请求 | ✅ 默认 200ms（当前实现是每次按键都请求） |
| 最短输入 | 2 字符 | ✅ 默认沿用现有实现（2 字符） |
| 失败 | 搜索无结果时**仍允许手工输入完整代码** | ✅ |

## 3. 主线 A：把账对上（S2）

### 3.1 ① 导入券商文件

#### 3.1.1 入口

```
导航：数据 → 券商对账 → [导入文件]
```

支持**一次拖入多个文件**（实测同账户的 ETF 与股票是两个文件）。
