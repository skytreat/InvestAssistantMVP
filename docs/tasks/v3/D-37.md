# D-37 · 回放起点 = 该标的在该券商的导入首行

## 现行口径（默认生效，待 owner 确认）

推导回放**从 0 起**，起点 = 事实层该标的在该券商的**导入首行**；**导入覆盖区间之外的期前持仓不并入**回放 frame。

## 理由（来自决策记录，不改写）

- SDD_v3 §9.3「无余额 → 按券商分别回放」**未定义**期前持仓口径；期初余额属于用户知识，不宜猜（同 INV-S2-36「不填假时间」精神）。
- 单行判定（`balance_after`）覆盖绝大多数行，纯回放仅兜底无余额旧格式；**用户修正可覆盖推导结果**是最终兜底（INV-S3-9）。

## 验收

- 期外持仓不进入回放；加 offset 参数后起点可调；用户修正优先于推导。
