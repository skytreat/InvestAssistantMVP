# D-35 · 券商导入/补录端点缺 admin 门

## 偏差

SDD §10.3 规定「导入与补录仅 admin」，但 v3.1 的 T122 写路由未加门，v3.1 audit 未把它列为 gate 项 ⇒ 漏检。

## 现状（实测，非计划勾选）

`apps/backend/src/routes/brokerImport.ts` 的 `broker-import/confirm`、`/batches/:id/revoke`、`/templates` POST 三个有副作用端点已返回 `403 FORBIDDEN`（admin 守卫在位）；`upload`/`preview` 与 GET 保持登录即可访问。**故按代码证据判 `closed`**（ADR-018 D2「证据分级：代码产物 > 计划勾选」）。

> ⚠️ ADR-018 §6 曾把 D-35 列为 P0 开放项；实测与 `v3-pending-decisions.md` 状态列（✅）一致，属**已关闭**，此处保留原卡备追溯（D-ID 不复用）。

## 验收

- 非 admin 调用三端点 → `403 FORBIDDEN`；admin（首个注册用户）→ 正常。
- `upload`/`preview`/GET 不受影响。
