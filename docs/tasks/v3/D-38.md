# D-38 · 异常分支保守判 `buy`

## 现行口径（默认生效，待 owner 确认）

`deriveFromBalance`：`bal <= qty` → `buy`（建仓）。即当 `buy` 且 `balance_after < quantity`（余额少于成交量）时，**保守判 buy**。

## 理由（来自决策记录，不改写）

- Requirements §3.2 只定义 `sell & 0 = clear`、`sell & >0 = reduce`、`buy & balance = qty = buy`、`> qty = add`，**未覆盖该异常形态**；实测两券商样本未出现。
- 若反判为 `reduce`，会虚拟出加仓价差，风险更高；判 `buy` 让持仓成本回归最近一次买入。

## 验收

- 异常形态回归用例覆盖；判 buy 不产生负持仓或虚假已实现盈亏。
